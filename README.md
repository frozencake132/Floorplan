# Floorplan Sketchpad

Sketch house floor plans with exact measurements: rooms, walls, doors, windows, stairs, furniture, labels and smart dimensions. Works on phones and computers, installs to the home screen, and runs offline.

**Open the app:** https://frozencake132.github.io/Floorplan/

**Install it:** on iPhone, open the link in Safari › Share › Add to Home Screen. On Android, open it in Chrome › ⋮ › Install app.

**Import a floor plan:** Projects › Import a floor plan picture. Upload a picture, screenshot or PDF; walls, doors, windows and openings are traced at real size (no furniture). Set one wall's real length and everything scales to match.

**Work together live:** in a project, tap Share › Share live and send the link. Whoever has the project open first hosts it; everyone else connects and sees edits as they happen.

Projects are saved on each person's own device. Use Projects › Back up everything to keep a copy.
